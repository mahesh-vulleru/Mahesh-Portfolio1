# Mahesh Portfolio — Iron Man / J.A.R.V.I.S. Theme

A responsive personal portfolio inspired by a futuristic Stark-style HUD. Built with plain HTML, CSS and JavaScript.

## Structure

```text
Mahesh-Portfolio-Ironman/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── .gitignore
└── README.md
```

## Run locally

No npm install or build step is required.

```bash
python -m http.server 5500
```

Open `http://localhost:5500`, or open `index.html` directly in a browser.

## Publish with GitHub Pages

1. Push the project files to a GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`.
5. Save and wait for GitHub Pages to publish.

## Before making the repository public

Review all personal details in `index.html`, especially CGPA, education dates, diploma score, certification names and dates, email, phone number, and project descriptions. Keep only information you can verify and are comfortable publishing.

## Notes

- Google Fonts are loaded from the internet; system font fallbacks are provided.
- The arc reactor and motion effects are drawn with Canvas.
- The page respects the visitor's reduced-motion preference.
